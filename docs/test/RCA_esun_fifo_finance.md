## 2. BUG-01：第 10／12／13／52 列追蹤

現行賣出分支：

```python
parts = _split_gross(trade.gross_amount, [a.quantity for a in alist])
```

當 `Σ allocation.qty < sell.quantity` 時，`pieces` 不含未配對殘量，卻仍用**整筆** `gross_amount`，使已配對片段價金＝全額。

|---|---|---|---|---:|---:|---:|---:|---:|---:|---:|

## 4. BUG-02／03 補充

- 三筆聚焦賣出之 `interest_txt` 皆為 `"0"`（明確 0）；高估主因是價金拆分，非利息。
- `_exceptions.csv` 僅有 `unmatched_quantity`，無 `matched_gross`／`unmatched_gross`；未配對殘量無法在報表側做價金／費用守恆核對。

## 5. 修正方向（對照計畫，實作見後續 TDD）

1. 賣出 `_split_gross` 的 `pieces` **納入未配對殘量**。
2. `income = sell_gross − commission − tax − interest`（費用／息僅第一賣出費用片段）。
3. 主明細 A～W 維持買進軸；新增配套「FIFO 配對及未配對明細」；強化 exceptions／audit 守恆欄；部分配對 W 註記。
